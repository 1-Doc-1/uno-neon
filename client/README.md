# Client UNO Néon (Angular)

Application Angular 22 (standalone, zoneless, signals). Voir `docs/SPEC.md` §10 et la section « Commandes » du
`CLAUDE.md` racine.

| Action                                          | Commande (depuis `client/`)               |
| ----------------------------------------------- | ----------------------------------------- |
| Serveur de dev (proxy `/ws` → `localhost:9001`) | `npm start`                               |
| Tests unitaires (Vitest)                        | `npm test`                                |
| Lint                                            | `npm run lint`                            |
| Formatage                                       | `npm run format` / `npm run format:check` |
| Build de production                             | `npm run build`                           |
